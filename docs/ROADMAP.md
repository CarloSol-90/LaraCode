# Hoja de ruta

Cada fase se dividirá en sesiones pequeñas y verificables, sin fechas ficticias.

## Fase 0 — Preparación

- [x] Proyecto Laravel y stack VILT
- [x] Configuración base de datos
- [x] Tests y herramientas de calidad
- [x] Documentación
- [x] Boost
- [x] Git

La conexión/migración MySQL queda condicionada a iniciar el servidor local.

## Fase 1 — Comprender el scaffold

- [ ] Recorrer carpetas
- [ ] Seguir una petición
- [ ] Comprender autenticación
- [ ] Comprender Vue e Inertia
- [ ] Realizar cambios visuales pequeños

## Fase 2 — Primera funcionalidad guiada

- [x] Elegir un recurso sencillo: primera ruta de aprendizaje
- [ ] Diseñar su tabla
- [ ] Crear migración
- [ ] Crear modelo
- [ ] Crear factory
- [ ] Crear test
- [ ] Crear ruta y controlador
- [ ] Renderizar con Inertia
- [ ] Mostrar con Vue

El primer contenido será la ruta `Laravel desde cero`, inicialmente con nombre, slug, descripción, nivel y estado de publicación. El progreso no será una columna de la ruta: pertenecerá posteriormente a la relación entre el usuario y el contenido educativo.
